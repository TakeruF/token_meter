# Token Meter 1.2.6

## English

This maintenance update makes the final minute before a quota reset clearer and includes additional verification for the reset countdown.

### Changes

- Fixed reset countdowns showing `Resets in 0m` while the reset was still up to 59 seconds away. They now show `Resets in <1m`.
- Added matching Japanese, Simplified Chinese, and Korean text for the new countdown.
- Added a boundary test covering both provider-reported quota windows and locally counted token windows.

### System Requirements

- macOS 14.0 or later
- Apple Silicon / Intel Mac (Universal Binary)

### Installation

Unzip `TokenMeter-1.2.6.zip` and move `TokenMeter.app` to `/Applications`. If you are already using Token Meter, you can update from the menu by clicking "Check for Updates…".

The app is Developer ID signed and notarized by Apple. The update ZIP is also verified by Sparkle's EdDSA signature.

## 한국어

이 유지 보수 업데이트는 한도 재설정 직전 마지막 1분의 표시를 더 정확하게 만들고 재설정 카운트다운 검증을 추가합니다.

### 변경 내용

- 재설정까지 최대 59초가 남아 있는데도 `0분 후 재설정`으로 표시되던 문제를 수정했습니다. 이제 `1분 이내 재설정`으로 표시됩니다.
- 새 카운트다운에 맞는 일본어, 간체 중국어, 한국어 문구를 추가했습니다.
- 제공자가 보고한 한도 시간창과 로컬 로그에서 계산한 토큰 시간창을 모두 다루는 경계 테스트를 추가했습니다.

### 작동 환경

- macOS 14.0 이상
- Apple Silicon / Intel Mac (Universal Binary)

### 설치 방법

`TokenMeter-1.2.6.zip` 압축을 풀고 `TokenMeter.app`을 `/Applications`로 이동하십시오. 이미 Token Meter를 사용 중인 경우 앱 내 'Check for Updates…'를 통해 업데이트할 수 있습니다.

앱은 Developer ID로 서명되었으며 Apple 공증(Notarization)을 받았습니다. 업데이트 ZIP은 Sparkle EdDSA 서명으로도 검증됩니다.
