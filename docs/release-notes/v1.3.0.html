Token Meter 1.3.0

English

This update lets you choose where each provider appears, and reorganizes Settings.

Changes

  • Add “Show providers in” to Settings. Choose separately for each provider whether it appears in the menu bar and in the popover — for example, show only Codex in the menu bar and still see Claude when you open the popover.
  • Hiding a provider from the menu bar or popover keeps collecting its usage. Dashboard and widgets still include every enabled provider.
  • The menu bar reset countdown now follows only the providers shown in the menu bar.
  • Reorganize Settings: language, number format, and Launch at login are grouped under General, and display settings come before less frequently used options such as refresh, data, and diagnostics.
  • Existing preferences are preserved. Every provider stays visible in the menu bar and popover until you change it.

System Requirements

  • macOS 14.0 or later
  • Apple Silicon / Intel Mac (Universal Binary)

Installation

Choose “Check for Updates…” in the app menu, or unzip TokenMeter-1.3.0.zip and move TokenMeter.app to /Applications.

The app is Developer ID signed and notarized by Apple. Sparkle verifies update ZIPs with an EdDSA signature.

日本語

プロバイダーごとに表示場所を選べるようにし、設定画面を整理しました。

変更内容

  • 設定に「表示場所」を追加しました。プロバイダーごとに、メニューバーとポップオーバーに表示するかを個別に選べます。たとえば、メニューバーにはCodexだけを表示し、ポップオーバーを開けばClaudeも確認できます。
  • メニューバーやポップオーバーで非表示にしても、使用量の収集は続きます。ダッシュボードとウィジェットには有効なすべてのプロバイダーが表示されます。
  • メニューバーのリセットまでのカウントダウンは、メニューバーに表示しているプロバイダーだけを対象にします。
  • 設定画面を整理しました。言語・数値の表記・ログイン時に起動を「一般」にまとめ、表示に関する設定を更新間隔・データ・診断など使用頻度の低い項目より前に配置しました。
  • 保存済みの設定は維持します。変更するまで、すべてのプロバイダーがメニューバーとポップオーバーに表示されます。

動作環境

  • macOS 14.0以降
  • Apple Silicon / Intel Mac（Universal Binary）

中文

本次更新可分别选择每个服务商的显示位置，并重新整理了设置界面。

变更内容

  • 设置中新增“显示位置”。可为每个服务商分别选择是否显示在菜单栏和弹出窗口中——例如菜单栏只显示 Codex，打开弹出窗口时仍可查看 Claude。

  • 菜单栏中的重置倒计时仅针对菜单栏中显示的服务商。
  • 重新整理设置界面：语言、数字格式和登录时启动归入“通用”，显示相关设置排在刷新、数据、诊断等较少使用的选项之前。
  • 已保存的设置保持不变。在更改之前，所有服务商都会显示在菜单栏和弹出窗口中。

한국어

제공자별로 표시 위치를 선택할 수 있게 하고 설정 화면을 정리했습니다.

변경 내용

  • 설정에 “표시 위치”를 추가했습니다. 제공자마다 메뉴 막대와 팝오버에 표시할지 따로 선택할 수 있습니다. 예를 들어 메뉴 막대에는 Codex만 표시하고, 팝오버를 열면 Claude도 확인할 수 있습니다.
  • 메뉴 막대나 팝오버에서 숨겨도 사용량 수집은 계속됩니다. 대시보드와 위젯에는 활성화된 모든 제공자가 표시됩니다.
  • 메뉴 막대의 초기화 카운트다운은 메뉴 막대에 표시된 제공자만 대상으로 합니다.
  • 설정 화면을 정리했습니다. 언어, 숫자 표기, 로그인 시 실행을 “일반”으로 묶고, 표시 관련 설정을 새로고침·데이터·진단 등 자주 쓰지 않는 항목보다 앞에 배치했습니다.
  • 저장된 설정은 유지됩니다. 변경하기 전까지 모든 제공자가 메뉴 막대와 팝오버에 표시됩니다.

작동 환경

  • macOS 14.0 이상
  • Apple Silicon / Intel Mac (Universal Binary)
