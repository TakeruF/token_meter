Token Meter 1.2.11

English

This update refreshes plan names and makes first-time setup easier to read.

Changes

  • Show Codex Pro 100, Pro 200, and Pro 500 instead of internal plan identifiers. Use current names for other recognized Codex plans, including Business.
  • Show the weekly account limit for all three Codex Pro tiers in the menu bar and provider card, without substituting a model-specific short window.
  • Update Claude usage guidance to cover subscription plans beyond Pro / Max, and remove Claude-specific OAuth guidance from Copilot connections.
  • Default to a compact menu bar with the Meter icon hidden on first launch. Existing saved preferences are preserved.
  • Fix the Japanese “Menu bar format” label wrapping vertically during onboarding. Refresh all four languages of setup and usage guidance.

System Requirements

  • macOS 14.0 or later
  • Apple Silicon / Intel Mac (Universal Binary)

Installation

Choose “Check for Updates…” in the app menu, or unzip TokenMeter-1.2.11.zip and move TokenMeter.app to /Applications.

The app is Developer ID signed and notarized by Apple. Sparkle verifies update ZIPs with an EdDSA signature.

変更内容

  • Codexの内部プラン名をPro 100・Pro 200・Pro 500として表示し、Businessなど他の認識済みプラン名も現行の表記に整理しました。
  • 3つのCodex Proプランすべてで、メニューバーとカードに週次のアカウント枠を表示します。モデル別の短時間枠では置き換えません。
  • Claudeの利用状況案内をPro / Max限定の表現から変更し、Copilotの接続案内に表示されていたClaude専用のOAuth説明を修正しました。
  • 初回起動時はメニューバーをコンパクト表示にし、Meterアイコンを非表示にします。保存済みの設定は維持します。
  • オンボーディングの「メニューバーの形式」が縦に折り返される問題を修正しました。設定・利用状況案内の4言語も更新しました。

動作環境

  • macOS 14.0以降
  • Apple Silicon / Intel Mac（Universal Binary）

インストール

メニューの「Check for Updates…」から更新するか、TokenMeter-1.2.11.zipを展開し、TokenMeter.appを/Applicationsへ移動してください。

アプリはDeveloper ID署名・Apple公証済みです。更新ZIPはSparkleのEdDSA署名で検証されます。
